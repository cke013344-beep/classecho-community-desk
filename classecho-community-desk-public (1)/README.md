# ClassEcho 社群运营工作台

面向 AI 学习工具的社群运营工作台。项目将日常选题、文案草稿、反馈跟进和运营复盘放在同一处，服务三个微信群的共用内容流程。

## AI 每日群消息

定时任务检索近期校园和留学资讯，核对原始来源，生成 150–200 字的候选草稿，再通过工作台提供的 MCP 接口存入当天记录。当天已有草稿时保留原稿。运营人员核对后自行发布到微信群。

我作为 ClassEcho 创业合伙人和产品运营，负责定义草稿规则、人工审核流程和验收标准。已通过手动试跑和实际定时运行验证日期、标题和草稿状态。

## 查看代码

- `app/mcp/route.ts` 包含读取当日上下文、保存草稿和记录失败的接口。
- `app/core.mjs` 包含排期、去重、记录、备份和复盘逻辑。
- `app/desk.tsx` 是工作台界面。`db/` 和 `drizzle/` 包含数据库结构与迁移。
- 云端定时任务由托管环境独立配置。公开源码包含接口和示例数据。

## 本地检查

使用 Node.js 22.13 或更新版本运行核心逻辑测试：

```sh
node --test app/core.test.mjs
```

安装项目依赖后，可用 `pnpm dev` 启动开发服务，或运行 `node build-local.mjs /绝对路径` 构建本地备用版。托管部署需连接自己的站点、数据库和自动化。
